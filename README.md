# Online Nursery System

Simple PHP/MySQL nursery e-commerce demo application.

## Overview

This repository contains a small online nursery system with admin and user sections for browsing plants, managing a cart, and placing orders.

## Requirements

- PHP 7.4+ (or compatible)
- MySQL / MariaDB
- Web server (Apache, Nginx) or PHP built-in server

## Setup

1. Clone the repository:

   git clone https://github.com/Refat123S/Online-Nursery-System_.git
   cd Online-Nursery-System_

2. Configure the database connection in `config/db.php` with your credentials.

3. Create a MySQL database and import any provided SQL (if available).

4. Serve the app (example using PHP built-in server):

   php -S localhost:8000

5. Open `http://localhost:8000` in your browser.

## Notes

- Update `config/db.php` instead of committing credentials.
- Consider adding a `.env` for sensitive settings.
